# qqbot_scheduler

QQ Bot Studio 的纯本地定时消息插件，不调用聊天大模型。

```text
/定时 08:00 早安
/定时 08:00 早安 2026-11-11~2026-11-20
/定时 12:00 午饭 周一、周三、周五
/定时 09:00 上班 工作日
/定时 列表
/定时 删除 <ID>
```

- 时间点为 `HH:MM`，时区默认 `Asia/Shanghai`。
- 日期段支持 `YYYY-MM-DD~YYYY-MM-DD`，也支持省略起始年份的 `MM-DD~MM-DD`。
- 星期支持 `周一`、`周1`、`星期一`、`一`，多个用 `、` 或 `,` 分隔，连续用 `~`。
- `工作日` / `非工作日` 优先使用在线节假日数据，网络失败回退到周末判断。
- 每个群的任务持久化在插件数据目录，重启后保留。
